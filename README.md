# VOA Contábil - Website Institucional

O website da **VOA Contábil** é a plataforma institucional do escritório, com sede em Manaus-AM, focada na apresentação de serviços de contabilidade empresarial nas áreas contábil, fiscal e trabalhista.

O projeto foi desenvolvido com foco em performance, acessibilidade e um design limpo e profissional, alinhado à identidade visual da empresa.

## ✨ Tecnologias Utilizadas

Este projeto é um website estático, utilizando as seguintes tecnologias principais:

* **HTML5:** Estrutura semântica do conteúdo.
* **CSS3:** Estilização, incluindo uso de variáveis CSS para gestão de tema e cores.
* **Bootstrap 5:** Framework para o sistema de grid e componentes.
* **JavaScript:** Para efeitos de animação.
